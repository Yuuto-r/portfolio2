# Portfolio Website

A React and Tailwind portfolio website template ready for GitHub Pages.

## Customize

Edit these files:

- `src/App.jsx` for your name, bio, projects, experience, links, and email
- `src/styles.css` for shared Tailwind component classes
- `tailwind.config.js` for theme colors, fonts, and design tokens

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, set `Source` to `GitHub Actions`.
5. Push to the `main` or `master` branch.

GitHub will install dependencies, build the React app, and publish the `dist`
folder. The live URL will appear in the workflow summary and in `Settings` ->
`Pages`.

## Local Preview

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
